0. PURPOSE OF THIS HANDOFF
======================================================================

This brief transfers the cocktail formulation research, modeling approach,
Supabase architecture, operating rules, and skill definition developed for
Perfect Harmony Group (PHG).

The goal is not to give Harmony another collection of cocktail “rules of thumb.”
The goal is to make Harmony capable of reasoning quantitatively about cocktail
balance using measurable formulation variables while still respecting sensory
reality and uncertainty.

The intended long-term behavior is:

1. Read a recipe and resolve each ingredient into what it actually contributes.
2. Calculate sugar, acid, ethanol, water/dilution, and service-condition effects.
3. Distinguish true measured/compositional facts from approximations.
4. Compare the resulting structure against relevant reference builds or
   operating windows.
5. Explain why a drink tastes the way it does.
6. Propose specific changes while showing assumptions.
7. Never invent precision when the ingredient composition is unknown.
8. Finalize balance by tasting at the actual service condition, especially
   temperature and frozen state.

This is a formulation and sensory reasoning system, not a simple ounce-ratio
calculator.

2. CORE PHILOSOPHY — HOW HARMONY SHOULD THINK
======================================================================

Do not reduce balance to:

    “2 oz spirit + 0.75 oz citrus + 0.75 oz simple”

That is a useful starting coordinate for one class of sour, but it is not a
universal definition of balance.

The PHG model treats a drink as a multi-variable system.

CORE QUANTITATIVE FINGERPRINT:

    sugar_g_100ml
    ta_g_100ml
    sugar_acid_ratio
    abv_finished
    dilution_pct
    service_temp_c

IMPORTANT MODIFIERS:

    acid identity
    sweetener identity
    carbonation
    bitterness
    salt
    aroma
    texture
    fat/protein/emulsion context where relevant
    ice format / continued dilution where relevant
    frozen state

This “balance fingerprint” is a PHG analytical framework derived from converging
professional practice, food/beverage science, and sensory research. It is not a
published universal industry standard.

The system must preserve BOTH:
- absolute concentration; and
- ratios.

Two drinks can have the exact same sugar:acid ratio and taste radically
different if one contains twice the sugar and twice the acid.

Example:

    Drink A
    sugar = 5.0 g/100 mL
    TA    = 0.6 g/100 mL
    ratio = 8.33

    Drink B
    sugar = 10.0 g/100 mL
    TA    = 1.2 g/100 mL
    ratio = 8.33

Same ratio.
Very different intensity.

Never throw away absolute concentration.

3. BRIX — WHAT IT IS AND WHAT IT IS NOT
======================================================================

PHG definition:

Degrees Brix is a soluble-solids scale referenced to sucrose. In an ideal
sucrose-water reference solution:

    1 °Bx ≈ 1 gram sucrose per 100 grams of solution.

For a PURE SUCROSE + WATER reference system:

    1:1 sucrose:water BY WEIGHT
    = 50% sucrose by mass
    = 50 °Bx ideal reference solution

    2:1 sucrose:water BY WEIGHT
    = 66.6667% sucrose by mass
    = ~66.7 °Bx ideal reference solution

Bartender reference values loaded into PHG:

    1:1 simple syrup BY VOLUME ≈ 48 °Bx
    2:1 rich syrup BY VOLUME  ≈ 65.1 °Bx

These volume-based numbers are working/reference values, not laws. Granulation,
packing, heating, temperature, evaporation, and preparation technique can move
the actual result.

CRITICAL RULE:

    BRIX IS NOT PERCEIVED SWEETNESS.

Brix is primarily a concentration / soluble-solids measurement. Perceived
sweetness depends on:

    sugar identity
    concentration
    acids
    ethanol
    aroma
    temperature
    matrix
    bitterness
    carbonation
    other dissolved materials

Do not translate Brix directly into “how sweet the cocktail tastes.”

======================================================================
4. TRUE BRIX VS APPARENT BRIX
======================================================================

Standard refractometers are calibrated around sucrose solutions.

In a cocktail containing ethanol, acids, salts, other sugars, juices,
liqueurs, and other dissolved solids, a refractometer can return a useful
reading but it is not necessarily “true sucrose Brix.”

PHG language:

    true Brix
        Use only where the matrix supports that interpretation, especially a
        sucrose-water reference solution.

    apparent Brix
        Use for a refractometer reading from an alcoholic or compositionally
        complex cocktail unless the matrix has been validated.

When precision matters:

    calculate actual sugar from ingredient composition
    rather than pretending the refractometer reading equals sugar concentration.

This is specifically important with alcoholic ingredients such as orange
liqueurs.

======================================================================
5. SUGARS — DO NOT TREAT ALL SUGARS AS EQUIVALENT
======================================================================

PHG uses sucrose as the reference sweetness = 1.0 where appropriate.

But:

    equal grams of sucrose, glucose, and fructose
    do NOT necessarily produce equal perceived sweetness.

Relative sweetness changes with:
- sugar identity
- concentration
- temperature
- test conditions
- beverage matrix

Therefore:

DO NOT create one universal permanent conversion such as:
    “fructose is always X times sucrose”

unless the conditions and source justify it.

Separate these concepts:

    chemical sugar mass
    Brix / soluble solids
    sucrose-equivalent sensory sweetness
    actual perceived sweetness

The first two can often be measured or calculated.
The last two are sensory models.

8. ACIDITY — TITRATABLE ACIDITY VS pH
======================================================================

PHG treats pH and titratable acidity as different measurements.

pH:
    describes hydrogen-ion activity.

TA / titratable acidity:
    represents the neutralizable acid load.

For cocktail structural balance, TA is usually the more useful quantity for
calculating the acid load contributed by a juice or acid-adjusted component.

However:

    TA does not fully predict perceived sourness.
    pH does not fully predict perceived sourness.

Sensory perception also depends on:
- acid identity
- concentration
- buffering
- sugar
- ethanol
- aroma
- temperature
- matrix

Do not replace one metric with the other.

9. CURRENT ACID WORKING MODELS
======================================================================

Cocktail-practitioner working model:

    fresh lemon juice ≈ 6% TA
    fresh lime juice  ≈ 6% TA

Lime-like acid model:

    ~4% citric acid
    ~2% malic acid
    total ≈ 6%

Orange working model:

    ~1% acid

These are FORMULATION WORKING MODELS, not statements that every lemon, lime, or
orange physically has those exact values.

Fruit varies with:
- cultivar
- maturity
- storage
- source
- harvest
- batch

When repeatability matters:
    measure the actual batch.

======================================================================
10. ACID ADJUSTMENT
======================================================================

PHG definition:

Acid adjustment adds measured acid—commonly citric and/or malic—to a lower-acid
juice so that its structural acidity approaches a desired target while preserving
the original fruit’s aromatic identity.

Common use cases:
    orange
    grapefruit
    pineapple
    other fruit juices

Important:
    acid-adjusted orange is NOT “chemically or sensorially identical to lemon.”
    The aroma, sugars, texture, bitterness, minerals, and other compounds remain
    different.

Use acid adjustment to manipulate structural acidity, not to pretend the fruit
became another fruit.

======================================================================
11. CORDIALS — SUGAR CAN DILUTE ACID CONCENTRATION
======================================================================

A common formulation mistake is to sweeten an acidic juice heavily and then
assume its acid intensity is unchanged.

Example:
    lime juice -> high-Brix lime cordial

When a large amount of sugar/water is introduced, the acid concentration of the
finished cordial can be lower than the starting juice.

Therefore:
    a cordial may need measured acid added back to restore the intended
    sweet-acid structure.

This matters especially when targeting a high standardized Brix.

Garret Richard / Jasper’s Mix reference loaded into PHG:

    approximately 66 Brix

The conceptual purpose is powerful:
    turn “sweet enough” into a repeatable formulation input.

But:
    66 Brix is a specific professional example,
    not a universal cordial target.

======================================================================
12. SWEET / SOUR PERCEPTUAL INTERACTION
======================================================================

Sweetness and sourness do not behave as two independent linear sliders.

Human sensory research supports mutual suppression:

    added sucrose can reduce perceived sourness
    added acid can reduce perceived sweetness

Therefore:

DO NOT model perception as:

    perceived sweetness = sugar - acid

or any simplistic universal subtraction rule.

Keep chemical structure separate from sensory interpretation.

The chemical fingerprint can tell Harmony what changed.
Sensory data and tasting tell Harmony how the change is experienced.

======================================================================
13. SUGAR / ACID RATIO
======================================================================

A useful structural ratio is:

    sugar_acid_ratio = sugar concentration / titratable acid concentration

If using Brix in a juice-standard style context, the USDA reference definition is
conceptually:

    Brix / grams acid per 100 g product

PHG should prefer internally consistent units and explicitly label them.

Never output a ratio without also retaining:
    sugar concentration
    acid concentration

Ratio alone hides intensity.

======================================================================
14. ETHANOL IS A SENSORY INGREDIENT
======================================================================

Do not treat ABV as merely a compliance or strength number.

Human ethanol sensory research loaded into PHG tested concentrations including:

    4%
    8%
    16%
    32%
    48% v/v

Findings support multiple ethanol sensations:

    sweetness
    bitterness
    drying
    burning / tingling

Dominant reported qualities shift with concentration.

Loaded finding:
    bitterness prominent around 8–16%
    burning/tingling prominent around 32–48%

Real cocktails are more complex than aqueous ethanol studies, but the main
formulation lesson is clear:

    changing ABV can change the perceived balance even if sugar and acid stay
    chemically constant.

======================================================================
15. DILUTION IS AN INGREDIENT
======================================================================

There is no universal “25% dilution is correct” rule.

Water changes:

    sugar concentration
    acid concentration
    ABV
    aroma release
    bitterness
    texture
    temperature
    total intensity

Shaken and stirred drinks can occupy different useful regions.

Harmony must track:

    pre_dilution_volume_ml
    finished_volume_ml
    dilution_pct

When possible, calculate dilution from measured pre/post weights or volumes for
a specific service protocol.

Do not silently apply one universal dilution constant across all drinks.

======================================================================
16. TEMPERATURE
======================================================================

Service temperature changes perceived sweetness and overall flavor.

Sensory research supports a concentration-dependent relationship between
temperature and sucrose sweetness.

Cooling can reduce perceived sweetness at lower-to-moderate sucrose
concentrations, while the magnitude of the temperature effect can decrease at
higher concentrations.

PHG practitioner service windows currently stored:

SHAKEN:
    approximately -10 °C to -5 °C

STIRRED:
    approximately -7 °C to -0.5 °C

These come from Dave Arnold practitioner guidance and are stored as HEURISTICS,
not universal laws.

Rule:

    colder is not automatically better.

Excessive cold can mute:
    aroma
    sweetness
    flavor differentiation

Always evaluate a drink at its actual service temperature.

======================================================================
17. FROZEN COCKTAIL MODEL
======================================================================

Frozen cocktails require a separate formulation mindset.

Both:
    sugar / dissolved solids
and:
    ethanol

depress the freezing point.

Texture therefore depends on at least:

    sugar / solids
    ABV
    total water
    temperature
    machine behavior
    other dissolved material
    optional hydrocolloid structure

Professional starting operating window currently stored:

    finished Brix: approximately 13–15
    finished ABV:  approximately 0–10%

CRITICAL:
These are operating / texture starting windows.

They are NOT:
    universal ideal sweetness
or:
    universal ideal alcohol levels

A particular machine may tolerate a different range.

Frozen final rule:

    TASTE THE DRINK FROZEN.

A room-temperature frozen batch is not the final sensory state.

Extreme cold alters:
    sweetness
    aroma
    bitterness
    texture

18. MULTI-ROLE INGREDIENT DECOMPOSITION
======================================================================

Do not assign one ingredient one role.

Example:
    Cointreau contributes:
        ethanol
        sugar
        orange aroma
        bitterness
        water
        other dissolved material

A vermouth might contribute:
    ethanol
    residual sugar
    acid
    bitterness
    aromatic compounds
    water

A fruit purée might contribute:
    sugar
    acid
    soluble solids
    fiber
    viscosity
    aroma
    water

Harmony must think in CONTRIBUTIONS, not labels.

27. CALCULATION MODEL
======================================================================

When the required ingredient composition is known, calculate contributions
ingredient by ingredient.

For an ingredient with a known sugar concentration:

    sugar_g_i =
        ingredient_volume_ml
        * sugar_g_100ml
        / 100

For a known titratable acidity:

    ta_g_i =
        ingredient_volume_ml
        * ta_g_100ml
        / 100

For ethanol:

    ethanol_ml_i =
        ingredient_volume_ml
        * abv_pct
        / 100

Totals:

    total_sugar_g = sum(sugar_g_i)

    total_ta_g = sum(ta_g_i)

    total_ethanol_ml = sum(ethanol_ml_i)

    pre_dilution_volume_ml = sum(ingredient liquid volumes)

After service dilution:

    finished_volume_ml =
        pre_dilution_volume_ml
        + dilution_water_ml
        + any explicit water/carbonated top where included

Then:

    sugar_g_100ml =
        total_sugar_g
        / finished_volume_ml
        * 100

    ta_g_100ml =
        total_ta_g
        / finished_volume_ml
        * 100

    sugar_acid_ratio =
        sugar_g_100ml / ta_g_100ml

    abv_finished =
        total_ethanol_ml
        / finished_volume_ml
        * 100

Dilution:

    dilution_pct =
        (finished_volume_ml - pre_dilution_volume_ml)
        / pre_dilution_volume_ml
        * 100

IMPORTANT:
These equations are only as valid as their inputs.

If the syrup strength is unknown:
    do not fake sugar_g.

If a liqueur sugar level is unknown:
    do not borrow another brand’s value.

If dilution is unknown:
    output a pre-dilution result or scenario range and label it.

If juice TA is a working model:
    label it as an assumption.

33. REQUIRED GUARDRAILS
======================================================================

1. Brix is not perceived sweetness.

2. pH is not TA.

3. Sugar/acid ratio does not replace absolute concentration.

4. “Simple syrup” does not automatically mean 50 Brix.

5. “Triple sec” does not automatically mean Cointreau.

6. A liqueur can add sugar + ethanol + aroma + bitterness + water at once.

7. Do not apply a single dilution percentage to all cocktails.

8. Taste at actual service temperature.

9. Frozen texture targets are not universal flavor targets.

10. Do not use a refractometer in an alcoholic matrix as if it directly reports
    grams of sugar.

11. Do not generate a precise recipe_balance_analysis if ingredient coverage is
    insufficient.

12. Preserve uncertainty. Ask for or request measurements when the missing input
    materially changes the answer.

13. Never write to PHG canonical recipe/menu data merely because an analysis
    suggests a change. Use PHG proposal/approval orchestration.

35. HOW HARMONY SHOULD HANDLE A FROZEN MARGARITA
======================================================================

Do NOT merely take the shaken Margarita and blend it with ice.

Evaluate:

    finished sugar / apparent or calculated solids
    finished ABV
    water load
    acid concentration
    machine target
    frozen service temperature
    texture

Starting operating window stored:

    13–15 Brix
    0–10% finished ABV

Then:
    tune acid and sensory sweetness at the final frozen temperature.

A batch that tastes balanced warm may taste dull, harsh, or insufficiently sweet
when frozen.

36. WHAT IS NOT FINISHED
======================================================================

The formulation system is a foundation, not a completed world model.

Known gaps:

1. Recipe ingredient coverage is incomplete.

2. Many base spirits are not yet mapped to formulation profiles.
   For sugar/acid calculation this may be acceptable when sugar/acid = 0 is
   product-appropriate, but ABV still needs product/spec confirmation.

3. Generic liqueurs need product-specific sugar + ABV data.

4. More juices need:
       Brix
       sugar composition
       TA
       pH
       acid identity
       batch variability

5. Densities are missing for many ingredients.
   This matters when converting between mass-based Brix and volume-based recipe
   quantities.

6. recipe_balance_analysis has not been populated.

7. Empirical PHG “corridors” for drink families still need to be learned from
   properly resolved recipes and sensory testing.

8. There is not yet a complete sucrose-equivalent sweetness engine for mixed
   sugars.

9. Carbonation, bitterness, salt, fat, protein, viscosity, and aroma are modeled
   conceptually but are not yet converted into one universal quantitative
   sensory equation—and they should not be forced into one prematurely.
