What happens for every state

The pipeline is the one Iowa, Colorado and New York already use. Only step 1 differs by state; everything after it is the same code.

  1. Licence listThe state's on-premise liquor licences (bars, restaurants, hotels), from open data, a file, or a records request. varies by state
  2. Venues + locationNormalise names and addresses, collapse stacked permits, geocode with the free Census geocoder. automated
  3. Google PlacesWebsite, phone, rating, type and exact coordinates for each venue. paid per venue
  4. Menu linksScan each website for drinks, cocktail, wine, beer and happy-hour menus; deep discovery for hard sites. automated
  5. Download + renderPDFs, images and HTML pages saved and turned into page images (the pipeline fixed today). automated
  6. Read + classifyDrinks, prices, brands, menu type; feeds the gallery, the map and Harmony. automated
  7. CensusACS 5-year ZIP (ZCTA) demographics for the whole state in one API pass. automated after one key

Census data: all 50 states in one run

The ingest-census-acs function already loads ACS 2020–2024 5-year estimates for a state through the Census API, normalised to the same shape as Iowa. It needs one thing from you: a free Census API key (signup at api.census.gov, takes minutes). Without a key the API rate-limits, which is why the current load leaned on Census Reporter.

With the key: every state's ZIP-level income, age, population and education tables load in one scheduled pass (about 33,800 ZCTAs nationwide), then refresh once a year when the Census Bureau publishes the next 5-year release. Nothing else is manual.

A baseline for the hard states. Where a state has no usable licence list, a free open places dataset (for example Overture Maps' bar and restaurant places) can seed venues right away, and the licence list replaces it when the records request comes back. Its licence terms need a check before we use it; Google Places text search by city is the paid alternative.

What you have to do by hand

Once

  • Census API key: sign up at api.census.gov/data/key_signup.html and send it to me; I store it as a server secret.
  • Google Places budget: set a monthly cap in Google Cloud for the Places API. At about 2–3.5¢ per venue, ~311k venues is roughly $6k–$11k spread over the rollout (estimate; Google's free monthly allowance lowers it).
  • Railway: deploy the HTML capture v2 worker (PHG-034); it captures more of each menu page for every state.
  • Paid lists: approve Indiana's bulk file ($150 + $10 per 1,000 records), Nebraska's roster ($40) and Delaware's master list ($25 if the free email request is slow).

Records requests and hand-offs, by state

Each is a one-time request (most states allow email); several should be repeated yearly to keep lists fresh.

  • IN · Buy a bulk Excel export at secure.in.gov/ai/appfiles/atc-license-bulk/ (filter to retailer permit types 210/211 etc.), roughly $150-$250 per pull; repeat periodically; Alternatively submit an APRA request via in.gov/atc/public-records for a full active-permit list
  • NE · Order the Active License Roster in Excel ($40) from NLCC (P.O. Box 95046, Lincoln NE 68509; pay via PayPort) and re-order periodically; OR scrape the free active.cgi Active License Holder listing on a schedule (verify it lists all rows)
  • NC · Email Contact@abc.nc.gov / file a public records request for all active retail on-premise permits with DBA and address; Or scrape abc2.nc.gov/Search/Permit by county
  • SC · Check the SCDOR 'License Searches & ABL Resources' page for any active-licence export; if only lookup, submit SC FOIA request to SCDOR ABL for a spreadsheet of active PBW, PO7 and LBD licences with addresses; Repeat request periodically (quarterly)
  • AL · Submit public records request at https://alabcboard.gov/public-records-request asking for all active on-premise retail licenses (CSV/XLSX) with addresses; Or scrape licensesearch.alabama.gov/AOWB county by county
  • LA · Submit public records request at atc.louisiana.gov/contact/public-records-requests for a spreadsheet of all active Class A-General and Class A-Restaurant permits; repeat periodically; Or scrape the LAATC license search portal
  • NV · Submit NRS 239 public records requests to Clark County Business License (702-455-4340), City of Las Vegas, Henderson, North Las Vegas, Washoe County, Reno, Sparks for active liquor licence lists; Or export category searches from Clark County Business License Search
  • AR · Send Arkansas FOIA request to ABC for all active retail on-premise permits (Excel); Optionally parse monthly Permit Change List PDFs to keep it current
  • NM · Submit an IPRA request to NM RLD (ABC Division, 505-476-4875) for all active liquor licences with type and premises address; Or scrape the NM-PLUS public search
  • WV · Submit WV FOIA request to WVABCA Licensing (ABCA.Licensing@wv.gov) for spreadsheet of all active retail on-premise (Class A / private club / restaurant) licences with addresses; Alternatively script the licensesearch.aspx form per county and licence type (55 counties)
  • HI · Download Maui licensee list PDF annually and parse; Submit UIPA request to Honolulu Liquor Commission for active licensee list (~2,500 licenses); Request lists from Kauai and Hawaii County liquor departments
  • NH · Email RightToKnow@liquor.nh.gov (or write 50 Storrs St, Concord NH 03301) requesting an electronic list of all active on-premise licensees with licence type, DBA and address; repeat periodically
  • MT · Email/call CARD licensing (406-444-6900) or file a public records request asking for an export of all active retail alcoholic beverage licences with licence number, DBA, address; Alternatively scrape the License Lookup at revenue.mt.gov/licenses (check terms)
  • RI · Submit APRA public records request to RI DBR (Division of Commercial Licensing, liquor) for the latest compiled municipal annual liquor licence reports (all active Class B/C/D etc.) in Excel; Optionally pull Providence ui7z-kv69 via Socrata API for Providence refreshes; Repeat annually after Dec 1 reporting deadline
  • DE · Email OABCCquestions@delaware.gov or buy the $25 retailer master list from the OABCC online portal; refresh periodically
  • SD · Email SD DOR Special Taxes Division (SpecialT@state.sd.us) requesting a spreadsheet of all active on-sale (liquor, wine, malt beverage) licences with premises addresses; If refused, collect city lists from Sioux Falls and Rapid City (largest markets) finance offices; Refresh annually (licences renew July 1)
  • AK · Use AK-ACCIS public license search and export/scrape Beverage Dispensary and Restaurant/Eating Place licenses, or email AMCO for a full active license export

Timeline

Week 1: Census key in, all states' census loaded. Wave 1 licence loaders built (each is a copy of the Colorado or New York loader pointed at a new dataset) and Places enrichment started for the largest states. Records requests for Wave 3 sent the same week, since they take 2–6 weeks to come back.

Weeks 2–3: Wave 2 exports and scrapers. Menus flow for Wave 1 as Places finishes (at today's pipeline speed, about 800 menus an hour).

Weeks 4–8: Wave 3 as request responses arrive; the open places baseline fills gaps in the meantime.

Licences require local approval: municipal governing body (finance officer) inside city limits, county commission (auditor) outside; the state DOR then issues.
  • Email SD DOR Special Taxes Division (SpecialT@state.sd.us) requesting a spreadsheet of all active on-sale (liquor, wine, malt beverage) licences with premises addresses
  • If refused, collect city lists from Sioux Falls and Rapid City (largest markets) finance offices

Low population; Sioux Falls and Rapid City cover most bars/restaurants. Tribal lands have separate tribal alcohol regulation.
