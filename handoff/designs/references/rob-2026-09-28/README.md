# Rob's reference concepts (2026-09-28)
This is the target quality bar for PHG menu design. The designer and critics compare against these.

| File | Concept | What it teaches |
|---|---|---|
| ref-01 | The Bistro, editorial single page | A giant vertical wordmark and an ink-wash plus gold-leaf art rail. Menu type is tracked caps with a small serif ingredient line, and prices sit in one column. Side-rail taglines ("GOOD FOOD / GOOD COMPANY"). Taglines appear on the section rules. Wine is set as producer · region with glass \| bottle prices. |
| ref-02 | 10 Cantina / Bistro variants (grid) | One content set run through 10 art directions: agave, papel-free botanicals, poster type, florals, dark and light grounds. The layout system stays constant while the art changes. |
| ref-03 | 10 more variants | Sunset gradients, cut-paper landscapes, vinyl, arches, collage, and a "Same Sun Different Night" script accent. |
| ref-04 | Solstice (landscape) | A photo and marble collage, a large sun disc behind the wordmark, a script tagline, and airy tracked-caps side lists. Cocktails are set as name / ingredient · ingredient lines. |
| ref-05..09 | The Greenhouse series | Immersive, fully illustrated themed worlds: the light and shadow split, jungle signage, the horror variant and the fantasy variant. The menu panels sit on the illustration as parchment or slate cards. Props (compass, books, glasses) carry the taglines. |

Pipeline lesson: these are raster art. The PHG approach is a text-free generated ART layer (via Canva generate-image) with an exact, sourced HTML TEXT layer on top.

AI-rendered lettering errors are visible in these references ("SIGKATTURE", "Eazy", "BRIGHT"). That is why menu text must never be baked into the image.

The Jumanji-branded variant uses trademarked IP, which is not usable for a real venue.
